# routes/

Input logs that reach useful places, for `./build/prime --replay=routes/<name>`. Each is the
`inputs.txt` of a recorded run (see `gcn-recomp/docs/diagnostics.md`); the memory card
snapshots are deliberately not kept, since a card holds the game's save data, so these routes
assume the card the run starts with has no Metroid Prime save on it.

- `new-game/` — title, *Start*, *New Game*, through the intro text into the opening cutscene.
  Gameplay on the frigate begins on its own around frame 9000.
