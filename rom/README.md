# rom/

Put **your own** disc image of *Metroid Prime* (USA, Rev 2, disc ID `GM8E01`) here as an
uncompressed `.iso` or a `.ciso`, e.g. `rom/game.iso`.

Everything in this directory except this README is ignored by git. Never commit or share
game images. See the top-level [README](../README.md) for how to dump your disc and
convert other formats.
